From the surface to the abyss — a cinematic journey through my work, skills, and experience. Immersive 3D scenes, ambient sound, and a live depth gauge follow every scroll.

**React 19** / **Vite** / **Three.js** / **React Three Fiber** / **Framer Motion**

### Run locally

```bash
npm install
npm run dev
```

### Ship

```bash
npm run build
npm run preview
```

Production output: `dist/`. Vercel is configured in [vercel.json](./vercel.json).
